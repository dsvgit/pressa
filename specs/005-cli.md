## Goal

Three subcommands via `clap`, plus tracing set up before anything else can fail.

## Sketch

```
pressa                    # = pressa dev
pressa dev                # open the TUI
pressa init               # scaffold pressa.yaml + .pressa/ in the current dir
pressa validate           # load and check the schema, print a summary, exit 0/1

Global: --project <dir>   bypass upward discovery
        --log-level <lvl> default info
```

- `init` refuses to overwrite an existing `pressa.yaml`.
- `init` writes the `examples/blog` schema as a starting point.
- `validate` prints errors to stderr with their YAML paths and exits 1.
- `tracing` writes to `.pressa/pressa.log`; nothing ever goes to stdout while
  the TUI is running.
- Errors before the TUI starts are printed plainly and exit non-zero.
